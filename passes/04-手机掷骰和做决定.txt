一、手机端（轮到你时）
- 轮到你：手机震一下，钱包下面出现操作区。按引擎 legalActions 显示按钮，文字和本地页 renderActions 一致：
  - 掷骰子：大按钮；也可以摇手机（DeviceMotion，加速度超过阈值算一次，0.8 秒内只算一次）。
    iPhone 第一次要点一下允许运动传感器（DeviceMotionEvent.requestPermission，必须在点击里调用）。
    注意：iPhone 只在 https 下给运动数据，局域网 http 下拿不到就只显示按钮，不报错；安卓 http 下能摇。
  - 在监狱：交罚金出狱 / 用出狱卡 / 掷骰碰运气。
  - 停在无主的地：买下 / 买下 + 盖 1 栋 / 买下 + 盖 2 栋 / 不买，每个按钮写上总价，买不起的置灰。
  - 停在自己的国家：加盖一栋 / 升级酒店。
  - 结束回合。
  - 欠钱：还清、宣告破产（要二次确认）。
- 「我的资产」列表（不轮到也能看，轮到时才能点）：每块地的国旗/图标、房子数、抵押状态，按钮有卖房、抵押贷款、还贷，规则和本地页 renderBank 一样。欠钱时靠它凑钱。
- 不轮到你时：显示「现在是 X 的回合」，操作区收起。
- 把地挂牌卖给其他人、抢购别人挂出的地，这一轮不做（pass 05）。

二、大屏端（只演）
- 每次服务器广播新局面，带上这次动作的事件。大屏用现有的 playEvents(prev, events) 按顺序播放：骰子、走棋、钱飞、买地盖章、盖房、入狱、抽卡、破产。语音和音效只在大屏放。
- 用 game.seq 防止重播：大屏刷新或重连时直接摆出当前局面，不补播旧事件。
- 大屏上原来要人点按钮的地方（ask 扣钱确认、showCard 翻卡后的按钮、破产清单），改成：
  大屏照常弹框，按钮换成「等 X 在手机上确认」；同时服务器让那个人的手机弹出同样的标题、金额和按钮（「付钱」「收下」「知道了」）。手机点了，服务器转给大屏，大屏继续往下演。
  该谁确认：付钱的人；抽卡的人；破产的人。
  那个人掉线，或者 20 秒没点，大屏自动继续。
- 动画没演完之前，服务器不收下一个操作（手机按钮置灰，显示「看大屏」）：大屏演完发 { t: 'played', seq } 给服务器才放行。没有大屏连着、或者大屏 15 秒没回，也放行，不能卡死。
- 回合 30 秒计时从大屏演完那一刻开始算。超时由服务器调用 autoAct（和在线版一样：自动掷骰、不买、结束回合）；掉线的玩家轮到时 3 秒后自动操作。
- 主持人按钮（大屏顶栏，替换原来隐藏的「新游戏」位置）：
  - 暂停 / 继续：暂停时 60 分钟时钟和回合计时都停住，大屏盖一层「已暂停」，手机按钮置灰。
  - 结束：二次确认后马上按净资产结算（直接用引擎现有的 endGame 和 ranking；如果引擎没导出，就只加一个导出的 finishNow(s, ctx)，不改别的规则）。
- 打完：大屏用现有 showResult 显示名次；手机显示自己第几名和净资产。大屏「再来一局」→ 回到二维码等人页，座位和角色保留，所有人「我选好了」重置为未选好。

三、服务器（party.js）
- 新增手机消息 act（内容和引擎 action 一样，服务器校验是不是轮到他、现在能不能动）、ack（确认弹框）；大屏消息 played、pause、resume、finish、again。
- 广播里带上 { events, seq, waitingFor }：waitingFor = 正在等谁在手机上确认（以及弹框内容），手机据此显示确认按钮。

保持不变：
规则.md 的规则和数字都不变。engine.js 只允许上面说的那一个导出，别的不改。本地试玩 / 和在线版 /online 照常能用。

完成的标准：
1. node test/sim.mjs 300 局全部通过；服务器开着时 node test/e2e.mjs 和 node test/party.mjs 通过。
2. test/party.mjs 加一段：一个假大屏（收到事件立刻回 played，收到 waitingFor 时不管）+ 3 个机器人手机，按 legalActions 随机操作、遇到确认就 ack，完整打完一局（有人破产到只剩一人，或者主持人发 finish 结算），每个手机收到自己的名次；再来一局能回到等人状态。
3. 另测：不轮到的人发 act 被拒；动画没放行时发 act 被拒；暂停时发 act 被拒；20 秒不确认会自动继续（测试里可以把时间调短，用环境变量）。
4. 浏览器里：大屏 + 2 个手机尺寸的标签页（localhost 和 127.0.0.1 各一个），手动走过掷骰、买地、付过路费（手机确认后钱才飞）、抽卡、进监狱各至少一次，各截一张图。把 Math.random 改掉来指定点数的办法在服务器上不灵，需要指定点数时用测试专用的环境变量（例如 PARTY_DICE=3,4,6,6），默认关闭。
